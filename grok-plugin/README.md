# Languals — Grok Build plugin

Connects Grok Build to the hosted Languals MCP server (`https://languals.fr/mcp`, streamable HTTP).

- Without an account: `languals_langues`, `languals_niveau_cecrl`, `languals_corriger`, `languals_traduire_expliquer`.
- With a Languals account (OAuth 2.1 + PKCE, dynamic client registration): tutor conversation, session notes, progress, flashcard reviews, pronunciation.

The tool list is served live by `tools/list`.
